# Chess-O-Pedia ♟️

An interactive, beginner-friendly web guide designed to help players learn chess fundamentals, board navigation, and piece strategies step by step.

🔗 **Live Demo:** [https://bytehub.github.io](https://bytehub.github.io)

---

## 📌 Features

- **Interactive Chapters:** Structured lessons covering board setup, piece movements, notation, and rules.
- **Clean UI:** Responsive design built with standard web technologies.
- **Light/Dark Theme:** Switch between visual modes for comfortable reading.
